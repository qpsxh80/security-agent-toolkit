# 2026-11-09 (월) Computer-010 아침 과제

## 찾아본 것
서버에서 로그를 옮기고 백업하는 방법: 서버에는 마우스(GUI)가 없으므로, 터미널 명령어(cp, mv, rm)를 사용해 파일을 복사하고, 이름을 변경하고, 필요 없는 로그를 삭제하여 디스크 공간을 관리하고 백업한다.

## 오늘 새로 쓴 명령
touch, cp, mv, rm, Tab 자동 완성

## 찾은 옵션
- 폴더째 복사: `-r`
- 덮어쓰기 전에 묻기: `-i`
- 폴더째 지우기: `-r`

## mv 의 두 가지 쓰임
- 이름 바꾸기: `mv b.log c.log`
- 옮기기: `mv c.log backup/`
