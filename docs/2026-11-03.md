## 결과를 파일에 남기기 (assignment_06)

### 한 일
- `assignment_06_f1.py`: `check.txt`에 "점검 시작", "점검 끝"을 쓰고 다시 읽어 출력
- `assignment_06_f2.py`: 없는 파일 `not-provided.txt`를 열 때 `FileNotFoundError`를 `try/except`로 처리
- 선택 문제 R1~R5: 파일 쓰기·읽기·덧붙이기, 로그 줄 수 세기, FAIL 줄만 출력

### 확인한 결과
- f1: "점검 시작", "점검 끝" 출력
- f2: "파일 위치를 확인하세요" 출력
- R3: 로그 6줄과 "총 6줄" 출력
- R4: FAIL이 든 4줄 출력
- R5: "점검 시작", "점검 끝", "추가 점검" 출력

### 새로 알게 된 점
- `open()`의 모드: `"w"`는 덮어쓰기, `"a"`는 덧붙이기, 생략하면 읽기
- `with`를 쓰면 파일이 자동으로 닫힌다
- `\n`을 붙여야 줄이 바뀐다. `print`가 이미 줄을 바꾸므로 파일 줄을 출력할 때는 `strip()`으로 `\n`을 지운다
- 없는 파일을 열면 `FileNotFoundError`가 난다
- `"FAIL" in line`으로 특정 글자가 든 줄만 골라낼 수 있다
