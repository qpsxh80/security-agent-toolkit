## Gemini API 키 발급 및 확인

### 오늘 한 것
Gemini API 키 발급, .env에 보관, .gitignore로 막기, curl로 확인

### 찾아보고 알게 된 것
- API 키는: LLM API를 호출할 때 사용자를 인증하고 사용량을 추적하는 비밀 문자열이다.
- 무료 등급은: 분당 요청 수(RPM)와 일일 요청 수(RPD)에 제한이 있다.
- 보안 담당자가 다루는 서버는: 대부분 Linux/Unix 기반이다.
- 깃배시를 쓰면: Windows에서도 Linux와 유사한 명령어(ls, pwd, grep 등)를 쓸 수 있다.

### 키가 틀렸을 때와 키가 없을 때의 차이
- 틀린 키: UNAUTHENTICATED
- 키 없음: PERMISSION_DENIED
