## 조건문 실습 (assignment_02)

### 한 일
- `assignment_02_f1.py`: `result == "FAIL"`일 때만 "확인 필요" 출력
- `assignment_02_f2.py`: `count >= 3`이면 "추가 확인", 아니면 "기록 유지" 출력

### 확인한 결과
- f1: `result = "FAIL"` → `확인 필요`
- f1: `result = "SUCCESS"` → `계속 진행`
- f2: `count = 2` → `기록 유지`
- f2: `count = 3` → `추가 확인`

### 새로 알게 된 점
- `=`는 값 저장, `==`는 값 비교에 쓴다.
- `if`/`else` 뒤에는 콜론(`:`)을 붙이고, 실행할 코드는 네 칸 들여쓴다.
- 경계값(`>= 3`에서 3)을 직접 바꿔보면 조건이 참/거짓으로 갈리는 지점을 확인할 수 있다.

## 리스트와 반복문 실습 (assignment_03)

### 한 일
- `assignment_03_f1.py`: `users` 리스트를 `for`로 하나씩 꺼내 출력
- `assignment_03_f2.py`: `range(1, 4)`로 1, 2, 3 출력

### 확인한 결과
- f1: `kim01`, `lee02`, `park03`이 한 줄씩 출력됨
- f1: `users`에 `"choi04"`를 추가하자 한 줄이 더 출력됨
- f2: `1`, `2`, `3`이 출력됨. `4`는 출력되지 않음

### 새로 알게 된 점
- 리스트는 `[]`로 감싸고 쉼표로 나눈다. 번호는 0부터 센다.
- `for 값 in 목록:`으로 목록에서 값을 하나씩 꺼내 반복한다.
- `range(1, 4)`는 1, 2, 3을 만든다. 끝값 4는 포함되지 않는다.
- `append()`로 리스트 맨 뒤에 값을 붙일 수 있다.
