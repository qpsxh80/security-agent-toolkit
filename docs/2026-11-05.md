### 찾아보고 알게 된 것

## 딕셔너리와 JSON (assignment_08)

### 한 일
- `assignment_08_f1.py`: 딕셔너리에서 키로 값을 꺼내 출력
- `assignment_08_f2.py`: 리스트를 `json.dump`로 저장하고 `json.load`로 복원
- 선택 문제 R1~R14와 도전 5-8, 6-8

### 확인한 결과
- f1: `kim01 4`
- f2: `kim01` (logs.json 저장 후 복원)
- R2: 계정 이름 5줄
- R3: "실패 4건"
- R8: 한글이 `\u...`로 깨짐
- R9: `ensure_ascii=False`로 한글 그대로
- R10: `indent=2`로 줄 나눔
- R11: `3`
- 도전 6-8: "실패 4건"

### 새로 알게 된 점
- 딕셔너리는 `{}`, 꺼낼 때는 `["key"]`. 없는 키에 대괄호를 쓰면 `KeyError`.
- 없을 수도 있는 키는 `.get("key", 기본값)`으로 안전하게 꺼낸다.
- JSON: `dumps`(값→글자), `loads`(글자→값), `dump`(값→파일), `load`(파일→값)
- 한글은 `ensure_ascii=False`, 줄 나눔은 `indent=2`

## Wireshark 설치 및 network_zt 폴더 (Computer-008)

Wireshark (Npcap 함께)

### 찾아보고 알게 된 것
- 보안 담당자가 패킷을 직접 열어 보는 이유는: 실제로 오가는 트래픽을 확인해 의심스러운 통신이나 비정상 패턴을 눈으로 잡아내기 위해서다.

- | (파이프)는: 앞 명령의 출력을 뒤 명령의 입력으로 넘겨주는 기호다.

## 함수 (assignment_09)

### 한 일
- `assignment_09_f1.py`: `greet(name)` 함수를 만들어 두 번 호출
- `assignment_09_f2.py`: `judge(fail_count)` 함수로 2와 3의 경계 판단
- 선택 문제 R1~R4: 함수 정의·호출·return·매개변수 연습

### 확인한 결과
- f1: "안녕하세요 기찬", "안녕하세요 정민"
- f2: "기록 유지"(2), "추가 확인"(3)
- R1: "점검을 시작합니다" 2번
- R2: "kim01"
- R3: True
- R4: ['kim01', 'park03']

### 새로 알게 된 점
- 함수는 `def 이름(매개변수):`로 정의하고, `이름(인자)`로 호출한다. 호출할 때 괄호를 빠뜨리면 실행되지 않는다.
- `print`는 화면에 보여주기만 하고, `return`은 값을 돌려준다. 결과를 다음에 쓸 함수는 `return`으로 끝낸다.
- `return`을 만나면 함수는 그 자리에서 끝난다. `return`이 없으면 `None`을 돌려준다.
